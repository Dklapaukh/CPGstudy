# Mentoring tracker (EAS clinical practice guidelines)

A phone-friendly page for working through the EAS CPGs with someone you are mentoring.
Each guideline can be marked Complete or Review, with notes, and filtered by status.
Progress is saved in the browser of the phone you use, and stays until you clear it.

## Files
- `index.html` – the whole tracker (this is the only file that matters)
- `.nojekyll` – tells GitHub to serve the page as it is (leave it alone)

## How to put it online (GitHub Pages)
1. Upload `index.html`, `.nojekyll` and `README.md` to this repository (Add file > Upload files > Commit changes).
2. Go to Settings > Pages.
3. Under "Build and deployment", set Source to "Deploy from a branch", Branch to `main`, folder `/ (root)`, then Save.
4. After a minute or two the page is live at https://dklapaukh.github.io/Mentoring/

## Things to know
- Notes and ticks live only in the browser they were made in. A different phone or browser starts blank.
- The guideline text comes from the St John EAS CPG export dated 24.09.2026. It is marked "uncontrolled", so check the official site for the current version.
- A public repository makes the page, and so the guideline text, public. Consider whether that suits you.
